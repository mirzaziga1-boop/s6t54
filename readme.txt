Luxury rent-a-car & tourism WordPress theme. Dark + gold branding, native 3-language
real-time switcher (BS/EN/AR + RTL, no plugin), Vehicle CPT with live fleet filter &
search, Elementor section widgets, Customizer-driven header/footer.

== Installation ==
1. Run build-zip.sh (or Compress-Archive) to create shams-albosnia.zip.
2. WP Admin > Appearance > Themes > Add New > Upload Theme > choose the zip > Install Now > Activate.
3. Add vehicles under "Vozni Park" (set category, year, seats, bags, transmission, fuel,
   price, CDW, airport badge, and per-language feature lines; upload a featured image).
4. Settings > Reading > set a static front page (the theme auto-renders the demo home if
   the page is not built with Elementor). Build/edit any page with the "Shams Al Bosnia"
   Elementor widgets for full control.
5. Appearance > Customize to set contact, social, logo, currency, footer promo and the
   trilingual headlines.
